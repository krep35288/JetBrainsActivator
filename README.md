# JB Activate (Windows)

PowerShell-скрипт для активации продуктов JetBrains на Windows через `ja-netfilter` с обязательной проверкой всех скачиваемых файлов через VirusTotal.

## Что делает

1. Скачивает `ja-netfilter.jar`, плагины и конфиги с `ckey.run`.
2. **Каждый скачанный файл проверяет через VirusTotal API** — если есть хоть один детект `malicious`/`suspicious`, скрипт останавливается и ничего не патчит.
3. Добавляет `-javaagent` в `.vmoptions` каждого установленного продукта JetBrains в `%APPDATA%\JetBrains\<Product>`.
4. Убирает `com.intellij.modules.ultimate` из `disabled_plugins.txt`.
5. Запрашивает `.key`-файл для каждого продукта и кладёт его рядом.
6. Делает бэкап всех изменяемых файлов в `~\.jb_run\backups\<timestamp>\`.

Ничего не требует от имени администратора, не трогает системные папки, не удаляет себя.

---

## Требования

- **Windows 10/11**
- **PowerShell 5.1+** (встроен в Windows)
- **Хотя бы одна установленная и запущенная JetBrains IDE** — иначе папка `%APPDATA%\JetBrains` не создастся
- **API-ключи VirusTotal** — от 1 до 50 штук ([получить бесплатно](https://www.virustotal.com/gui/my-apikey))
